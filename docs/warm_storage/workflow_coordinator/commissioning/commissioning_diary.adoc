== Commissioning disposition -- fixed launchers close here

Classification:: *COORDINATOR MECHANICS*; *ORCHESTRATION LOGIC*.

Fixed task-specific Python launchers were intentionally useful during
commissioning: they made the WorkItem, authority, scope, one-shot consumption,
state root, provider binding, and expected result explicit.  After multiple
materially different real N=1 Runs, the repeated launcher mechanics have become
accidental complexity.  No further task-specific production launcher should be
created merely to execute another ordinary N=1 WorkItem.  A future concrete
defect or proof requirement may justify another fixed launcher only for that
bounded reason.

The next intended Coordinator engineering step is a generic N=1 operator/CLI
with declarative human-authored configuration, implemented conventionally and
then dogfooded once through a real N=1 WorkItem.  This diary does not claim that
the future CLI design has already been accepted beyond current repository
authority.  Bounded N>1 / Slice 5 remains a later step and is not authorized by
this diary.

The three `.py.txt` launcher records under `launchers/` are historical evidence,
not supported repository executables.  Ignored `tmp/` launcher copies are no
longer durable authority and may be removed manually after this curation; this
record neither deletes them nor alters the trusted external Run roots.
