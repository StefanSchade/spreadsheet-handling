== B1 -- attempt accounting and evidence

`operator.py::main` now has an explicit two-region shell contract:

* pre-attempt/pre-provider work (argument/configuration checks, Git/head/clean
  checks, pinned input loading, N=1 validation, fresh state-root creation, Run
  construction, and plan write) returns `2` on failure;
* the attempt/provider-capable region starts at checkout registration. Any
  exception from that point returns `1`, without exception-type reclassification.

On an attempt-region failure, `operator-summary.json` is written best-effort.
It preserves known Run, invocation, checkout, provider, and safely observable
Git facts; unavailable observations are omitted. It records `operator_status:
failed` and the original error, so it cannot represent a clean operator success.
Evidence-writing failures are suppressed and never replace the original error.
No recovery semantics were copied or added; an authoritative Run returned by
`run_real_one_hop` remains the source of known Run facts.

The direct regression test executes a fake provider exactly once, then forces a
post-provider summary/observation failure. It proves exit `1`, plan presence,
failure-summary presence, and no second invocation.

== B2 -- genuine N>1 proof
