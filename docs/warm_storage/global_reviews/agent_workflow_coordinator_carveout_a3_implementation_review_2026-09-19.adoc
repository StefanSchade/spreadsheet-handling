== 8. Loader and digest

`REVIEWED_SHA256` equals `sha256sum` of the committed bytes
(`058fde86...a194`). `resources.files(__package__) / "resources" / "..."` is
Python-3.10 compatible and derives no path from repository, cwd, `__file__`
parents or environment. Order: read bytes -> `OSError`/`TypeError` -> stable
error; digest mismatch -> same error; strict UTF-8 decode -> same error; frozen
dataclass value. No prologue/ID/version runtime parsing. `byte_count`/`sha256`
are derived from `text.encode("utf-8")`, which round-trips exactly for the ASCII
admitted bytes (probe: re-encoded text equals file bytes).

Probes: `PermissionError`, `IsADirectoryError`, generic `OSError`, altered and
empty bytes all raise `CoordinatorResourceError`. `files()` raising
`ModuleNotFoundError` leaks as-is; not an ordinary missing/unreadable resource
case (the package is already imported), so no finding.
