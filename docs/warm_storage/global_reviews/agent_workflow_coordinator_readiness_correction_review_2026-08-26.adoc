== 6. Direct correction-regression check

*Result: NO direct material correction regression.*

The correction-adjacent risk surface was inspected specifically (new
architecture<->FTR contradictions; impossible acceptance criteria; authority
leaks from the repair; a common reconcile path losing a required distinction;
`durable_artifact` recreating ceremony; component selection becoming a hidden
DSL; the non-DMC fixture forcing engine special-casing; crash fixes requiring
unavailable atomic guarantees; tracked-ignore making first-time setup
impossible; matrix vs slice contradictions; ID/reference inconsistency). Findings:

* No new contradiction: all eight repairs correspond across architecture and FTR;
  no third contract.
* No impossible acceptance criterion: the new/changed ACs (Slice-1 AC3/AC5,
  Slice-2 AC2, Slice-3 AC4/AC6, Replay J) are reducer- or fixture-testable.
* No authority leak: R1/R2 strictly *narrow* authority; R4's "applicable explicit
  resume/human authority" preserves the crash-vs-prerequisite distinction.
* Atomic guarantees are available: the design relies only on atomic file
  replacement (temp-write + rename on one filesystem), not database transactions;
  `WFC-PERSIST-02` requires persistent local storage. No event store reintroduced.
* First-time setup is possible: the ignore preflight reads Git ignore resolution
  for a (possibly non-existent) path and fails closed with an actionable
  diagnostic; the maintainer commits a one-line tracked ignore entry. No
  self-deadlock or circular preflight.
* Component selection is static data (`components: {role: [...], repository_policy:
  [...]}`), not a computed/conditional expression; `WFC-PROFILE-05`/`PROMPT-04`
  still forbid conditionals/loops/computed graphs -- not a hidden DSL.

Two *non-material* implementation notes (recorded, not regressions, not
reopeners; they do not affect readiness):

. *R3 example command precision.* Architecture 8 illustrates the ignore preflight
  with "`git check-ignore --no-index`". Bare `git check-ignore` reports a path as
  ignored even when only `.git/info/exclude` matches, so the *tracked-vs-local*
  distinction the requirement mandates needs source-aware checking (e.g.
  `git check-ignore -v` and rejecting a `.git/info/exclude` source, or confirming
  the matching rule is committed). The normative contract (`WFC-PERSIST-02`) and
  Slice-2 AC2 already force the correct behaviour, so the parenthetical example is
  merely imprecise; the implementer should not read `--no-index` alone as
  sufficient.
. *Replay "J" label alignment.* The FTR labels the non-DMC fixture as replay/matrix
  "J" and validates "matrix J"; the architecture describes the same fixture in
  section 13 and refers to "A--I tests and the non-DMC bug-workflow replay"
  (section 16) without the "J" label. The *content* corresponds; only the label
  differs. A one-line alignment (label the architecture entry "J", or note in the
  FTR that J = the section-13 fixture) would make the cross-artifact "matrix J"
  reference mechanically resolvable. Optional tidy-up; not blocking.

Neither note meets the bar for a direct material regression (each fails the
"materially affects implementation readiness" test), and neither reopens R3 or R7.
