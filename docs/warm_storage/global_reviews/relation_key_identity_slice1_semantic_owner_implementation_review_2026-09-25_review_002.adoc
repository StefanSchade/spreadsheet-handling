== Independent assessment

The owner meets the accepted bounded contract.

* Eligibility is exactly non-Missing scalar admission. `relation_key_identity`
  returns no identity for a Missing component, so Missing cannot equal itself
  as a key; composite identities likewise reject any Missing component.
* The frozen `RelationKeyIdentity` is category tagged and is the one object
  used for equality and hashing. String/Number and Boolean/Number therefore
  cannot inherit Python equality, while Strings retain every whitespace
  character unchanged.
* Number tokens use exact integer material or `as_integer_ratio()` material;
  they do not use a promoted NumPy dtype or a lossy `float()` conversion.
  Infinities are handled separately and signed zero shares one exact value.
* Date and DateTime are distinct tags. DateTime coordinates are rational
  day coordinates: naive Python, pandas, and NumPy carriers compare by the
  same wall-clock coordinate; aware Python and pandas carriers compare by UTC
  instant; aware and naive values have distinct tags. The NumPy implementation
  derives fixed-unit ticks and calendar `Y`/`M` coordinates directly, avoiding
  cross-unit NumPy comparisons and retaining sub-microsecond precision.
* The implementation remains a narrowly named private Domain owner. It does
  not normalize stored values, create a general Scalar equality API, or migrate
  any consumer.

The committed tests cover the assessment's semantic-owner matrix: exact
Strings and whitespace, category boundaries, equal and non-promoted Number
cases, all named Missing carriers, identity/hash agreement, the naive
NumPy/pandas/Python non-transitive DateTime triple, aware instant equality,
aware/naive separation, Date/DateTime separation, and ordered composite keys.
They also cover W2's `numpy.longdouble` no-loss requirement. Focused direct
probes additionally exercised `uint64`, infinities, signed zero, fixed and
calendar DateTime units, exact cross-carrier coordinates, and retained
nanosecond precision.
