== Scope implemented

Slice 1 adds repository-local developer tooling under
`scripts/workflow_coordinator/`: immutable typed WorkItem, Run, Hop, Finding,
profile, result, observation, and dispatch-marker records; strict human-authored
YAML validation; deterministic machine-written Run JSON; the five finite route
effects; explicit mechanical preemption followed by deterministic reduction;
gate/human-only Finding dispositions; Hop accounting; one shared
reconcile/resume path; atomic Run and dispatch anchors; and a generated
checkpoint projection.

Repository/Git facts used by replays are typed observations. No Git transaction
engine, prompt assembly, fake or real adapter, provider invocation, autonomous
execution loop, evidence plugin system, production workflow profile, product
runtime change, or Slice 2--5 scaffold was added.

== Implementation shape and simplifications

* `model.py` contains frozen records and finite value vocabularies, not services.
* `serialization.py` performs explicit fail-closed parsing with no schema
  framework or second human-authoring format.
* `reducer.py` keeps the auditable flow `state + result + profile -> preemption
  -> Finding authority -> route/stop`. Supervisor confirmation accepts only a
  declared finite route and has no Finding-disposition parameter.
* `persistence.py` uses same-directory temporary files, `fsync`, and atomic
  replacement for the two trusted anchors. Checkpoints remain generated views;
  route keys are never stored in Run state.
* One `require_reconcile` mechanism serves both `interruption` and
  `prerequisite_return`; it records reason/anchor provenance and never restores
  a stale action or creates a rebaseline counter.

The implementation is approximately 1,555 lines excluding tests. The direct
tests are approximately 968 lines plus 180 lines of typed fixture helpers. This
size is dominated by explicit strict decoding and accepted model fields; no
removable service/interface/factory/registry layer was found in the
anti-overengineering review.
