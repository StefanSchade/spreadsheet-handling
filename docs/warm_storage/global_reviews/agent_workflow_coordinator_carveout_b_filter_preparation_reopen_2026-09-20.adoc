=== 3.1 Relevant pinned implementation

The installed source performs `sanity_check` unless `--force` was supplied or
the repository is recognized as already filtered. `--refs` sets `partial =
True`, disables automatic repacking/fetching, and does *not* bypass the check.
For the non-bare actual filter inputs relevant here, the check requires:

* ordinary `.git` placement and no case/Unicode-normalized ref collision;
* a fresh packed-object shape: at most one pack, fewer than 100 loose objects,
  and no mixed pack/loose state except permitted replace-ref objects;
* precisely one remote named `origin` (the no-remote exception applies only to
  a new bare repository with no packs);
* at most one line in every reflog file;
* no `refs/stash`;
* no staged, unstaged, or relevant untracked worktree content;
* for every `refs/heads/<name>`, an equal
  `refs/remotes/origin/<name>`; and
* exactly one worktree.

The same source shows why cleanup must be after filtering. With partial mode,
the normal origin-to-local-ref migration and automatic origin removal are
skipped. Ref deletion for exported-but-not-imported refs is also suppressed.
Thus `--refs refs/heads/main` rewrites local `main` only; an existing
`origin/main` is neither selected nor deleted.

== 7. `--refs`, partial mode, and object safety

=== 7.1 Ref behavior proved

Pinned behavior and both probes agree:

* `--refs refs/heads/main` implies partial mode;
* only local `refs/heads/main` is exported/imported and rewritten;
* `refs/remotes/origin/main` remains unchanged at the original anchor;
* partial mode retains `origin` and suppresses automatic cleanup/repacking;
* until explicit cleanup, original anchor history remains reachable through
  `origin/main`; and
* after direct and symbolic remote-ref cleanup, it is unreachable and the sole
  result ref is rewritten local `main`.

Thus retaining `origin/main` is necessary before invocation but unsafe as a
final result. The revised order satisfies both constraints.

=== 7.2 Physical presence versus reachability

The three repositories have different roles:
