== 4. Failure truthfulness

`_initialize_disposable_git_workspace` catches `subprocess.CalledProcessError`
and re-raises `OSError` with curated diagnostics; `run_smoke` catches that
`OSError`, records `diagnostics`, writes the best-effort summary, and returns `1`
without constructing or executing the adapter. The deterministic failure test
confirms `smoke_status=local_pre_execution_error`,
`invocation_attempted=False`, `configured_executable_smoke_succeeded=False`, a
useful diagnostic in the durable summary, exactly one initialization attempt, and
that the adapter is never constructed (`MustNotConstructAdapter`).

A missing `git` binary raises `FileNotFoundError` (a subclass of `OSError`) that
bypasses the helper's `CalledProcessError` wrapper but is still caught by the
outer `except OSError` in `run_smoke`; it is therefore classified identically as
a proven local pre-execution error without adapter execution, only with a
less-decorated diagnostic string. This is truthful and non-misleading (see
WATCH-1).

GIT INIT FAILURE BLOCKS EXECUTION:: YES +
GIT INIT FAILURE EVIDENCE TRUTHFUL:: YES

helper would only improve the diagnostic string.
