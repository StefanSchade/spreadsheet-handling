== Post-run architecture finding

The completed Run was mechanically successful under its declared focused
evidence profile, but its accepted H001 change was not sufficient evidence of
repository-wide correctness. Post-run full-suite validation exposed the
pre-existing architecture invariant in
`tests/architecture/test_execution_state_not_wired.py::test_execution_state_does_not_import_orchestrator_or_router`:
H001 had introduced the forbidden dependency
`pipeline.execution_state -> io_backends.router`.

This was a locally plausible but architecturally invalid domain/application
implementation and review/validation miss. H002's validation/evidence scope
included focused tests, `diff_hygiene`, and `git_version`, but not the
architecture guard or complete repository invariant. Focused agent-reported
tests are therefore not repository-wide acceptance evidence. The result does
not retroactively make the Run failed or show a reducer, routing, or
state-machine failure: the Run completed under its declared profile, and the
repository change subsequently required correction.
