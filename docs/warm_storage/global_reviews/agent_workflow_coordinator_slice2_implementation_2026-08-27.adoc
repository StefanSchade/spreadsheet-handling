== Scope and shape

Slice 2 adds `scripts/workflow_coordinator/git_facts.py` and `evidence.py`, plus
real temporary-Git fixture tests. The Git module directly executes and records
Git facts: repository identity, HEAD, porcelain cleanliness, base-to-head
range, commits, paths, ancestry, merge status, and submodule status. It records
claimed commits separately from independently observed commits. It never resets,
cleans, merges, rebases, or otherwise repairs a repository.

`preflight_state_root()` requires verbose `git check-ignore` to identify a
tracked `.gitignore` source; a match sourced only from `.git/info/exclude` fails
closed before any state-root write. `evidence.py` has a fixed in-code two-entry
callable table and executes only its fixed argv with `shell=False`; observations
are data and carry no semantic-acceptance operation.

The existing `recover_uncertain_dispatch()` remains the sole crash route. It now
retains independently observed actual commits for a marked uncertain dispatch,
then uses the existing `require_reconcile()` / explicit resume boundary.

== Crash and measurements

The marker/no-mutation fixture charges exactly one Hop and requires reconcile;
the absent-marker case charges none. The marked-with-commit fixture observes its
actual Git range before recovery, retains that commit in the charged Hop,
requires explicit resume, and proves repeated recovery is idempotent.

WFC-RRQ-01 measurements are recorded, not interpreted as thresholds: the
representative zero-commit range has 0 changed files; the one-commit fixture has
1 changed file (`src/one.txt`, 4 content bytes); the legitimate two-commit range
has 2 changed files (`src/one.txt`, `src/two.txt`, 8 content bytes). Evidence
command output is compact (the Git-version result's first-line summary and its
SHA-256 digest). No prompt or diff threshold was invented.

== Readability and boundary review

The transaction is reconstructable in one Git-facts module: observe/preflight,
then observe range/classify. There is no Git-library layer, command hierarchy,
provider plugin framework, adapter, prompt abstraction, or autonomous loop.
The fixed evidence table is intentionally data, not discovery machinery.
