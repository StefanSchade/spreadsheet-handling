== Independent assessment

The implementation meets the accepted bounded contract.

* The new value provider maps only non-Missing `RelationKeyIdentity` values
  and resolves each source key through the same owner. This gives value-mode
  materialization exact String behavior, category separation, integral Number
  equivalence, and Missing exclusion without a Core-to-Domain dependency.
* `check_unresolvable_fks`, target-value matching in `check_helper_values`,
  and both policy-declared and fallback `check_duplicate_ids` paths use
  `relation_key_identity`. The old `_norm_key`, the local unresolvable-key
  normalizer, nullable-String counting, and literal-`"nan"` exclusion are
  absent.
* Helper payload comparison remains explicitly local as
  `_helper_payload_comparison_value`; it is not reused to select target rows.
  This preserves the distinct helper-payload contract while making the
  relation-key handoff readable.
* Focused tests demonstrate the five required producer/validator pairs:
  whitespace and Number/String pairs are unequal, `1.0` and `1` agree, and
  empty String and `None` are ineligible. They also cover `numpy.int64(1)`,
  Boolean/Number separation, all named Missing duplicate carriers, literal
  `"nan"` duplicates, policy-independent fallback, policy-declared targets,
  and the registered `validate` fail mode.
* The release-note bullet is under `== unknown -- planned`, truthfully calls
  out exact String identity, category separation, integral Number equivalence,
  Missing exclusion, literal `"nan"`, and the absence of a general scalar
  normalization change.
