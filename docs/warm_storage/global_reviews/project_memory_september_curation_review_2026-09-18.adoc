== 10. Findings

=== PMR-M1 -- MINOR -- Two authority statements read broader than the adopted rule

Observation:: The `DEC-WFC-TRUSTED-COMMIT-AUTHORITY` title "Agent requests do not grant repository authority" and the `REV-WFC-OUTER-LOOP-AUTHORITY` takeaway "Agent recommendations, requested routes, and task selection cannot manufacture authority" are both in present tense. The implemented and accepted rule is narrower: a `CommitIntent` cannot land a mutation without phase `edit`+`commit`. The source review's open F1 shows the broader claim is currently *not* enforced across Runs: a trusted commit can land governing inputs that authorize the next Run.
Evidence:: Outer-loop review §2 and F1 ("currently unproven by anything except repository write access"); FTR action-authority section; decision `key`/`rationale` (accurate).
Risk if ignored:: A later reader or agent that relies on the title or takeaway could treat cross-Run self-governance as closed. This is mitigated by `FIN-WFC-OUTER-F1` being open and by the concern summary naming governing-input authority as open, which is why the finding is MINOR rather than IMPORTANT.
Action:: Narrow the decision title to trusted-commit scope, for example "Agent CommitIntent does not grant commit authority". Rephrase the takeaway normatively: "must not manufacture authority; currently enforced within one Run only (F1 open)". Optionally cite the FTR action-authority section as `source_path`, with the review as evidence.
