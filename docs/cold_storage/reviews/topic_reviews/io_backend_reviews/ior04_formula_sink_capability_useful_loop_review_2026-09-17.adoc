== Assessment

The correction removes the projection-local FormulaSpec sink-name vocabulary.
`io_backends.router` now declares the ODS and XLSX saver callables once,
maps both `ods` and its `calc` alias to the same ODS callable in `SAVERS`, and
derives `FORMULA_CAPABLE_SINK_KINDS` from those router entries.  Consequently,
`calc` inherits the ODS capability through the maintained router authority
instead of requiring another synchronized sink-name set.  The projection and
managed execution consume that exported authority.

The focused unit regression accepts `xlsx`, `ods`, and `calc`, and preserves
fail-closed rejection for `json`, `csv`, `yaml_dir`, and an unknown sink.  This
is within the permitted implementation paths and preserves the intended public
behavior except for the false rejection of `calc`.
