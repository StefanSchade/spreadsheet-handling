= FK/Reference-Helper DMC Hardening — Historical Evidence Index

This directory holds historical review evidence from the ongoing Domain
Maintainer Contract (DMC) hardening program's first bounded pilot, the
FK/reference-helper family (roadmap Phase F). It is archived navigation
material, not current authority.

Current normative authority for FK/reference-helper behavior lives in the
Domain Maintainer Contract
(`docs/developer_guide/ch06_code_conventions/05_domain_maintainer_contract.adoc`),
the current Functional/Semantic/Technical Model documents (in particular
`docs/functional_model/ch04_use_case_concepts/fk_helpers.adoc`,
`docs/semantic_model/12_contract_matrices.adoc`, and
`docs/technical_model/ch04_concepts/fk_helper_metadata.adoc`), and the
current runtime under `src/spreadsheet_handling/domain/transformations/`. Do
not treat any document in this directory as current behavioral authority;
consult the sources above first and use this evidence only for provenance
and reasoning history.

== How the pieces fit together

Deletion authority was a *nested required subproblem* of the FK/reference-helper
pilot, surfaced by the H5 slice -- it is not a separate Domain family, and its
closure does not itself advance or decide the enclosing FK/reference-helper
hardening cycle (Family cycles 1-7, per
`docs/backlog/roadmap_domain_hardening_sequence.adoc`).

[source,text]
----
DMC hardening
  -> FK/reference-helper family (Phase F, first bounded pilot)
    -> Cycle 0 (cycle_0/)
    -> H5 provenance handoff slice (provenance_handoff/)
      -> FK helper deletion authority subroutine (deletion_authority/) -- CLOSED
    -> Family cycles 1-7 (remaining; see roadmap) -- ACTIVE
----

The enclosing FK/reference-helper family hardening remains active and
unfinished: Family cycle 1 (remove remaining ontology) is IN PROGRESS, and
Family cycles 2-7 have not started. The deferred Cycle-0 finding F-002
(`derived_column_policy.py`'s Lookup-shape reimplementation) and
`FTR-FK-REFERENCE-HELPER-SURFACE-CONSOLIDATION-P5` (choosing one canonical
public helper-column surface between `add_fk_helpers` and
`add_lookup_helpers`) are separate, open, and not resolved by this
directory's evidence.
