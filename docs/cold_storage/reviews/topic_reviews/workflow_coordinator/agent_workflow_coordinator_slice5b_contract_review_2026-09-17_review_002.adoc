accepted authority. The defect is only that the "complete" change list omits one
fixture-visible consequence. No real-provider path depends on direct agent commits,
and no fail-closed path weakens.
Risk if ignored:: an implementation review could treat conversion of that
fixture as an undeclared regression.

path or to a negative case. The implementation review shall treat the change as
belonging to C3 item 7 and the accepted 4B authority model. No contract
