== N-1 root cause

Correction 2 put the ownership predicate in
`pipeline.dotted_paths.ensure_configuration_addressable` and called it from
the two direct configuration surfaces. The generic binders followed a separate
resolution path:

[source,text]
----
direct colon step selects make_frames_target_step
  -> build passes configuration target="...domain.ingress..."
  -> make_frames_target_step
  -> _resolve_target
  -> former _resolve_callable
  -> import + getattr without ownership check
----

Therefore an allowed outer factory could receive a blocked ingress callable as
its nested string `target`. The package export, coordinator, and rule targets
all built and invoked through that route in Acceptance Review 3.

== Shared correction boundary

Correction 3 chose the single-resolver design. The pipeline-local
`pipeline.dotted_paths.resolve_configuration_callable` now owns this complete
sequence:

. validate and split `module:function` or `module.function`;
. apply the explicit namespace ownership predicate;
. import the module;
. obtain the named attribute; and
. validate callability.

`make_plugin_step`, `resolve_registration`, and `_resolve_target` all delegate
to it. The former duplicate import/getattr implementations were removed from
`pipeline.steps` and `pipeline.registry`. An architecture guard asserts that
the shared resolver is the sole pipeline `importlib.import_module` owner and
that both consumers use it.

The dependency direction remains pipeline-to-pipeline. The generic resolver
imports no domain implementation module. Its ownership data is the single
explicit namespace:

[source,text]
----
spreadsheet_handling.domain.ingress
----

Exact namespace equality and descendant matching block the package and all
children without blocking the broader `spreadsheet_handling.domain` namespace.
No generic permission framework or Python security sandbox was introduced.

=== Independent rejection probe

[source,shell]
----
PYTHONPATH=src .venv/bin/python - <<'PY'
import importlib
from spreadsheet_handling.domain import ingress as ingress_package
from spreadsheet_handling.domain.ingress import coordinator, legend_blocks
from spreadsheet_handling.pipeline import dotted_paths
from spreadsheet_handling.pipeline.build import build_steps_from_config

targets = (
    ('spreadsheet_handling.domain.ingress:run_domain_ingress', ingress_package, 'run_domain_ingress'),
    ('spreadsheet_handling.domain.ingress.coordinator:run_domain_ingress', coordinator, 'run_domain_ingress'),
    ('spreadsheet_handling.domain.ingress.legend_blocks:normalize_legend_blocks_shape', legend_blocks, 'normalize_legend_blocks_shape'),
)
real_import = importlib.import_module
nested_verified = 0
direct_verified = 0
for target, owner, attribute in targets:
    original = getattr(owner, attribute)
    invoked = [False]
    imported = []
    def sentinel(*args, **kwargs):
        invoked[0] = True
        raise AssertionError('ingress target invoked')
    def import_sentinel(module_path):
        imported.append(module_path)
        if module_path.startswith('spreadsheet_handling.domain.ingress'):
            raise AssertionError(f'ingress imported: {module_path}')
        return real_import(module_path)
    setattr(owner, attribute, sentinel)
    dotted_paths.importlib.import_module = import_sentinel
    try:
        nested = {
            'step': 'spreadsheet_handling.pipeline.steps:make_frames_target_step',
            'target': target,
            'name': 'forbidden_nested',
        }
        try:
            build_steps_from_config([nested])
        except ValueError as exc:
            assert 'framework-internal and not configuration/plugin-addressable' in str(exc)
        else:
            raise AssertionError(f'nested target accepted: {target}')
        assert not invoked[0]
        assert not any(path.startswith('spreadsheet_handling.domain.ingress') for path in imported)
        nested_verified += 1
        for surface in ('plugin', 'colon_factory'):
            spec = ({'step': 'plugin', 'dotted': target} if surface == 'plugin' else {'step': target})
            try:
                build_steps_from_config([spec])
            except ValueError as exc:
                assert 'framework-internal and not configuration/plugin-addressable' in str(exc)
            else:
                raise AssertionError(f'{surface} accepted: {target}')
            assert not invoked[0]
            direct_verified += 1
    finally:
        dotted_paths.importlib.import_module = real_import
        setattr(owner, attribute, original)
print(f'{nested_verified}/3 nested routes rejected before target import/invocation')
print(f'{direct_verified}/6 direct routes rejected before import/invocation')
PY
