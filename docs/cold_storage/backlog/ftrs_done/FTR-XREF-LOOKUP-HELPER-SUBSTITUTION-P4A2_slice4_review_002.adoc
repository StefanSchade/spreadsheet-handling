== 7. Root cause and Makefile correction

The original failure was not package discovery. The dependency setup sequence
first produced a normal installed wheel and then a dev editable install, but
the order-only domain-contract stamp later invoked
`tools/pip_install_spec.sh -s .` without `-E`. Pip therefore replaced the
editable distribution with a non-editable copied tree. Because that copy came
from a pre-removal state and ordinary rebuild did not guarantee removal of
obsolete owned files, the deleted module remained importable.

Correction 001 changes the domain-contract stamp to:

[source,make]
----
tools/pip_install_spec.sh -p "$(PYTHON)" -s '.[dev]' -E
----

This matches the dev and project-memory editable convention and preserves the
development environment's final install mode. The ordinary runtime dependency
stamp remains non-editable by design, but `make setup` finishes with the dev
editable stamp and the corrected domain-contract stamp no longer clobbers it.

The shell helper was inspected completely. `-E` adds pip's `-e`, the quoted
extras specification is passed as one install specification, errors propagate,
and no alternate install path bypasses the corrected Makefile recipe.
