== 16. Canonical and lookup result

The original relation contains four distinct expected rows across `s1`/`s2`
and `Alice`/`Bob`/`Carol`. `_ordered` performs only a stable sort on
`[story_id, character_name]` and resets the index; comparison keeps every row
and every column and relaxes only backend dtype differences. It does not drop
duplicates or subset columns.

Consequently the comparison would fail if a legitimate row were lost, an
unexpected column appeared, a duplicate appeared, `title` were melted, or the
edited text leaked as a relation value. Independent assertions additionally
exclude `title` and the edited value. The authoritative lookup comparison is
separate and proves both original titles remain unchanged.
