== 8. FK-HR-014 — source-side key truth

Tracing `apply_fk_helpers` establishes the second argument's identity:

. it selects `fk.fk_column` from the source frame;
. converts that series to a list named `raw_ids` in value-mode code;
. passes that exact list positionally to the selected provider.

The elements are therefore source-side FK-column key values. The formula
provider does not read, normalize, compare, or branch on any element; it only
iterates the list once to preserve output cardinality and order. `source_keys`
is truthful at the shared callback boundary, while
`[formula for _ in source_keys]` makes cardinality-only use explicit.

Alternatives were assessed independently: `raw_ids` overstates value
inspection; `rows`/`source_rows` falsely suggest row objects; `row_count_inputs`
obscures the shared key-valued contract; `items` is too generic. A split
value/formula callback would be disproportionate and unauthorized. FK-HR-014 is
addressed. *Pass.*
