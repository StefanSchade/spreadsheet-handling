==== 1. Objective and scope control

Per the task brief, the goal is a fresh competent agent being able to
understand current Trusted-Ingress architecture from Semantic Model +
Technical Model + Developer Guide + interfaces/gates + relevant ADRs + module
structure + local source comments, *without* reading the 7,661-line FTR, its
frozen E1 review ledger (7,885 lines), the E2-E7 slice reviews (13 files,
~11,000 lines combined), or the Dotted-Extension review history. See
<<fresh-agent-test>> for the operational test.

This design artifact does not: change `src/` or `tests/`; redesign E1-E7;
change public APIs; add Phase-F requirements; write a Domain Maintainer
Contract; begin D-T3; archive historical evidence; or mark documentation
closure complete. It identifies canonical content, assigns durable homes, and
sequences bounded implementation slices with review gates.

===== C. Execution authority (11 invariants)

*Corrected scope (Blocking B-2):* the original five rows (now C1-C5) capture
certificate/binding immutability but not the accepted controlled execution-
state *lifecycle* the parent FTR requires the Technical Model to own --
which roles may be non-ordinary, how they compose, and what happens to them
on an uncertified return. C6-C11 below are the smallest coherent addition
that closes that gap, reconstructed directly from FTR §7 ("Ordinary payload
grammar and controlled framework roles"), §10 ("Structural-carrier
contract"), §17 ("Downstream postconditions"), and §20 ("Normative-style
contract sentences for later promotion") -- not guessed from this design's
own prior hypothesis. The historical E4/E5 correction-cycle discussion that
produced these final sections (FTR §31-45) is not recreated; only the final
accepted lifecycle is promoted here, per <<historical-only>>.

[cols="1,5,2,2",options="header"]
|===
| # | Invariant (paraphrase) | Evidence | Nature

| C6 | Ordinary Ingress-Conformant Domain state and Conformant Framework
  Execution State are categorically distinct:
  `ConformantFrameworkExecutionState ::= OrdinaryFactsOutsideControlledRoles

  under an explicit declared `ControlledRole`, never by external ingress or

  `LookupFormulaSpec` at a declared helper-cell role (framework-authored
