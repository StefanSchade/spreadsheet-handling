*Decisions confirmed:*::

* List and mapping forms remain supported external authoring forms.
* List form normalizes once per external metadata ingress to an ordered mapping.
* Canonical runtime, validation, render, persistence, and framework-owned
  carrier shape is mapping only.
* `name`, then `id`, then `legend_<position>` resolves list identity.
* Duplicate resolved block identities and non-mapping list members fail at
  ingress; entry-value policy is untouched.
* Mapping-form Intent is preserved without observable change; `resolved` is
  separately pruned as Resolution.
* Direct low-level/domain callers must provide canonical Frames or explicitly
  invoke ingress.

*Ingress / egress architecture:*::

Create an internal, extensible `domain.ingress` Frames-to-Frames coordinator.
Invoke it automatically after orchestrator load and after the two maintained
configuration-to-meta merges (`bootstrap_meta`, `apply_overrides`). All current
router backend and normal CLI/config/schema-maintenance application paths are
then covered.

Ingress is not registered or YAML-addressable. This follows the repository's
recognizable internal-domain-transformation pattern while avoiding a
Legend-specific helper hidden in orchestration.

Reserve `domain.egress` as the future name for automatic framework-owned
projection/pruning when Frames leave the domain. Do not implement a generic
egress framework here. Framework egress is distinct from user-declared
`pipeline_cleanup`, which executes explicit drop/keep commands.

*Remaining implementation scope:*::

* ingress coordinator, Legend shape rule, and three automatic invocation paths;
* downstream mapping-only simplification;
* ingress/readback `resolved` pruning with fresh carrier-local production;
* XLSX/ODS parity guards and own-sheet legend exclusion;
* meta-registry correction and focused architecture tests; and
* live documentation/release-note updates for canonical persisted shape and
  lower-level compatibility.

*Removed or deferred:*::

Removed obsolete line references, repeated evidence, the superseded human
decision, parser-side list-normalization speculation, and the now-resolved
Sparse Defaults mismatch. Deferred entry-value policy, `placement.target`
maintenance, generic metadata schemas, public ingress/egress YAML, generic
egress implementation, and broad orchestrator/projection redesign.

*Slice assessment:*::

The slice remains coherent. Its runtime work is one boundary contract:
external authoring sugar enters canonical domain Frames, render-local
Resolution serves carrier reconstruction, and support surfaces/Resolution do
not leak back into payload/canonical state.
