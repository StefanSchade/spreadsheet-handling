== I-3R root cause

The first correction guarded only `make_plugin_step`. A second maintained
configuration route remained in `pipeline.registry.resolve_registration`:
any colon-style `step: module:function` value was imported and treated as a
factory. That resolver did not share the plugin ownership check, so package,
coordinator, and rule ingress callables could execute during config
construction when the configuration supplied a literal `frames` argument.
Their result was not a valid `BoundStep`, but the framework-owned macro
callable had already been invoked.

== Common ownership boundary

`pipeline.dotted_paths.ensure_configuration_addressable` is now the one
pipeline-local ownership-boundary helper for configuration-addressed dotted
callables. It contains only an explicit string namespace declaration for
`spreadsheet_handling.domain.ingress`; it imports no domain module and does not
introduce a generic permission or security framework.

Both maintained routes call the helper before their importer:

* `make_plugin_step` checks `dotted` before `_resolve_callable`;
* `resolve_registration` checks a colon-style `step_id` before
  `importlib.import_module`.

The helper extracts the module part from supported `module:function` and
`module.function` references, rejects the exact internal package and every
descendant, and emits:

[source,text]
----
framework-internal and not configuration/plugin-addressable
----

It also gives deterministic pre-import failures for a non-string reference,
whitespace, empty/trailing separators, or multiple colon separators. Direct
colon-style step factories continue to use `module:function`; final-dot
`module.function` resolution remains the plugin surface's supported alternate
form, not a new direct-step syntax.

== Compatibility

* External colon-style step factories still build and execute.
* The existing internal domain-contract utility plugin remains addressable.
* A legitimate internal colon-style factory
  (`spreadsheet_handling.pipeline.steps:make_identity_step`) remains
  addressable.
* Registered short names are resolved before the dotted ownership helper and
  remain unchanged.
* Direct Python callable targets passed to generic binders are not dotted
  configuration values and remain supported.
* The boundary blocks only the exact
  `spreadsheet_handling.domain.ingress` namespace and descendants; it does not
  block the broader domain package.
* External modules that deliberately re-export an internal callable remain
  ordinary plugin code and are outside this configuration-address contract;
  the plugin mechanism is not treated as a Python sandbox.

=== Manual six-route invocation-sentinel probe

[source,shell]

PYTHONPATH=src .venv/bin/python - <<'PY'
from spreadsheet_handling.domain import ingress as ingress_package
from spreadsheet_handling.domain.ingress import coordinator, legend_blocks
from spreadsheet_handling.pipeline.build import build_steps_from_config

targets = (
    ('spreadsheet_handling.domain.ingress:run_domain_ingress', ingress_package, 'run_domain_ingress'),
    ('spreadsheet_handling.domain.ingress.coordinator:run_domain_ingress', coordinator, 'run_domain_ingress'),
    ('spreadsheet_handling.domain.ingress.legend_blocks:normalize_legend_blocks_shape', legend_blocks, 'normalize_legend_blocks_shape'),
)
verified = 0
for target, owner, attribute in targets:
    original = getattr(owner, attribute)
    invoked = [False]
    def sentinel(*args, **kwargs):
        invoked[0] = True
        raise AssertionError('ingress target invoked')
    setattr(owner, attribute, sentinel)
    try:
        for surface in ('plugin', 'colon_factory'):
            spec = ({'step': 'plugin', 'dotted': target} if surface == 'plugin' else {'step': target, 'frames': {'_meta': {'legend_blocks': None}}})
            try:
                build_steps_from_config([spec])
            except ValueError as exc:
                assert 'framework-internal and not configuration/plugin-addressable' in str(exc)
            else:
                raise AssertionError(f'{surface} accepted {target}')
            assert invoked[0] is False
            verified += 1
    finally:
        setattr(owner, attribute, original)
print(f'{verified}/6 configuration routes rejected before invocation')
PY
----

== Risks and lifecycle

macro-flow package must make its own ownership decision rather than being
silently swept into a broad domain block. External re-export aliases are
trusted plugin code, not an addressability bypass the framework can classify
without becoming a Python sandbox.

low-level canonical-Frames preconditions, and overlap/tampered carrier hints
